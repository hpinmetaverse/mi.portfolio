# mi.portfolio

Personal portfolio website for Himanshu Patil — *The Wandering Engineer*.

## Features

- Elegant Japanese-inspired typography (`Shippori Mincho` & `Zen Kaku Gothic New`)
- Adaptive Dark / Light theme support
- Smooth micro-interactions and custom noise canvas overlay
- Showcase of featured projects and research

## Local Development

To view the portfolio locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/hpinmetaverse/mi.portfolio.git
   cd mi.portfolio
   ```
2. Open `index.html` in any browser:
   ```bash
   open index.html
   ```

## Remote Workflow

When working remotely or making updates:

```bash
# Pull latest changes
git pull origin main

# Make changes, then stage and commit
git add .
git commit -m "Update portfolio content"

# Push to GitHub
git push origin main
```
